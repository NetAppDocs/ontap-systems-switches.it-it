= Collega gli shelf di dischi NS224 come storage collegato tramite switch agli switch di storage NVIDIA SN2100
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Collega gli alloggiamenti per unità NS224 come storage collegato a switch utilizzando gli switch di storage NVIDIA SN2100 quando lo storage collegato direttamente non è adatto alla tua configurazione.

* Il cavo NS224 guida gli scaffali attraverso gli switch di archiviazione:
+
https://library.netapp.com/ecm/ecm_download_file/ECMLP2876580["Informazioni per il cablaggio degli scaffali delle unità NS224 collegate allo switch"^]

* Installa i tuoi switch di archiviazione:
+
https://docs.netapp.com/us-en/ontap-systems-switches/index.html["Documentazione sugli switch AFF e FAS"^]

* Verifica l'hardware supportato, come switch e cavi di archiviazione, per il modello della tua piattaforma. Consulta la link:https://hwu.netapp.com/["Hardware Universe"^] per i dettagli.
