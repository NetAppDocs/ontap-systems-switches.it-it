= Installa l'hardware per lo switch di archiviazione NVIDIA SN2100
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Installa l'hardware dello switch di storage NVIDIA SN2100 seguendo la documentazione di NVIDIA. L'installazione dell'hardware è il primo passo prima di configurare lo switch per il funzionamento della rete di storage.

Segui questi passaggi per installare e configurare gli switch SN2100. Consulta la documentazione di NVIDIA per istruzioni dettagliate.

.Passi
. Rivedere illink:configure-reqs-sn2100-storage.html["requisiti di configurazione"] .
. Seguire le istruzioni nel link:https://networking-docs.nvidia.com/sn2000hw/latest/installation["Guida all'installazione dello switch NVIDIA"^].


.Cosa succederà ora?
Dopo aver installato l'hardware, puoilink:cabling-considerations-sn2100-storage.html["rivedere il cablaggio e la configurazione"] requisiti.
