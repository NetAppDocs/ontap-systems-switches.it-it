= Procedura di installazione del software per gli switch cluster Cisco Nexus 92300YC
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Segui questo workflow per installare il software NX-OS e il file di configurazione di riferimento (RCF) sugli switch di cluster Cisco Nexus 92300YC.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Uno"]link:configure-install-initial.html["Configurare l'interruttore"]
[role="quick-margin-para"]
Configura lo switch di cluster 92300YC.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Due"]link:install-nxos-overview.html["Prepararsi all'installazione del software NX-OS e RCF"]
[role="quick-margin-para"]
Il software Cisco NX-OS e i file di configurazione di riferimento (RCF) devono essere installati sugli switch di cluster Cisco 92300YC.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Tre"]link:install-nxos-software.html["Installa o aggiorna il software NX-OS"]
[role="quick-margin-para"]
Scarica e installa o aggiorna il software NX-OS sullo switch di cluster Cisco 392300YC.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Quattro"]link:install-the-rcf-file.html["Installare l'RCF"]
[role="quick-margin-para"]
Installa l'RCF dopo aver configurato per la prima volta lo switch Cisco 92300YC.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["Cinque"]link:configure-ssh-keys.html["Verifica la configurazione SSH"]
[role="quick-margin-para"]
Verifica che SSH sia abilitato sugli switch per poter utilizzare le funzionalità di monitoraggio dello stato degli switch Ethernet (CSHM) e di raccolta dei log.
