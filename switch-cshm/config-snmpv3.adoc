= Configura SNMPv3 per il monitoraggio dello stato di salute degli switch Ethernet
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Configura SNMPv3 sugli switch di rete per abilitare una comunicazione sicura e autenticata con l'Ethernet switch health monitor (CSHM). SNMPv3 fornisce un polling crittografato dello stato degli switch per il monitoraggio dello stato di salute in ONTAP.

L'Ethernet Switch Health Monitor (CSHM) utilizza SNMP per monitorare lo stato e le prestazioni degli switch di rete. Per impostazione predefinita, SNMPv2c viene configurato automaticamente tramite il Reference Configuration File (RCF). SNMPv3 è più sicuro di SNMPv2 perché introduce robuste funzionalità di sicurezza come autenticazione, crittografia e integrità dei messaggi, che proteggono dall'accesso non autorizzato e garantiscono la riservatezza e l'integrità dei dati durante la trasmissione.

[NOTE]
====
* SNMPv3 è supportato solo su ONTAP 9.12.1 e versioni successive.
* ONTAP 9.13.1P12, 9.14.1P9, 9.15.1P5, 9.16.1 e versioni successive risolvono questi due problemi:
+
** link:https://kb.netapp.com/on-prem/ontap/OHW/OHW-Issues/CONTAP-82891["Per il monitoraggio dello stato ONTAP degli switch Cisco , il traffico SNMPv2 potrebbe essere ancora visibile dopo il passaggio a SNMPv3 per il monitoraggio"^]
** link:https://kb.netapp.com/on-prem/ontap/OHW/OHW-Issues/CONTAP-119131["Avvisi falsi positivi sulla ventola e sull'alimentazione quando si verificano errori SNMP"^]




====
.Informazioni su questo compito
I seguenti comandi vengono utilizzati per configurare un nome utente SNMPv3 sugli switch *Broadcom*, * Cisco* e * NVIDIA*:

[role="tabbed-block"]
====
.Switch Broadcom
--
Configurare un nome utente SNMPv3 NETWORK-OPERATOR sugli switch Broadcom BES-53248.


NOTE: A partire da ONTAP 9.20.1, puoi configurare l'autenticazione SHA-512 sugli switch Broadcom.

* Per *nessuna autenticazione*:
+
[source, cli]
----
snmp-server user <snmpv3-user> NETWORK-OPERATOR noauth
----
* Per l'autenticazione *MD5/SHA/SHA-512*:
+
[source, cli]
----
snmp-server user <snmpv3-user> NETWORK-OPERATOR [auth-md5|auth-sha|auth-sha512]
----
* Per l'autenticazione *MD5/SHA/SHA-512 con crittografia AES/DES*:
+
[source, cli]
----
snmp-server user <snmpv3-user> NETWORK-OPERATOR [auth-md5|auth-sha|auth-sha512] [priv-aes128|priv-des]
----


Il seguente comando configura un nome utente SNMPv3 sul lato ONTAP :

[source, cli]
----
security login create -user-or-group-name <snmpv3-user> -application snmp -authentication-method usm -remote-switch-ipaddress <address>
----
Il seguente comando stabilisce il nome utente SNMPv3 con CSHM:

[source, cli]
----
cluster1::*> system switch ethernet modify -device <switch-name> -snmp-version SNMPv3 -community-or-username <snmpv3-user>
----
.Passaggi di esempio

.Switch Cisco
--
Configura un nome utente SNMPv3 `<snmpv3-user>` sugli switch Cisco Nexus.


NOTE: A partire da ONTAP 9.20.1, puoi configurare l'autenticazione SHA-512 o SHA-256 sugli switch Cisco.

* Per *nessuna autenticazione*:
+
[source, cli]
----
snmp-server user <snmpv3-user> NoAuth
----
* Per l'autenticazione *MD5/SHA/SHA-256/SHA-512*:
+
[source, cli]
----
snmp-server user <snmpv3-user> auth [md5|sha|sha-256|sha-512] <auth-password>
----
* Per l'autenticazione *MD5/SHA/SHA-256/SHA-512 con crittografia AES/DES*:
+
[source, cli]
----
snmp-server user <snmpv3-user> AuthEncrypt auth [md5|sha|sha-256|sha-512] <auth-password> priv [aes-128|des] <priv-password>
----
