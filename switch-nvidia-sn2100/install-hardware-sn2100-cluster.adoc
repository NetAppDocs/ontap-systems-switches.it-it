= Installa l'hardware per lo switch di cluster NVIDIA SN2100
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Installa l'hardware dello switch cluster NVIDIA SN2100 seguendo la documentazione di NVIDIA. L'installazione dell'hardware è il primo passo prima di configurare lo switch per il funzionamento in cluster.

Segui questi passaggi per installare e configurare gli switch SN2100. Consulta la documentazione di NVIDIA per istruzioni dettagliate.

.Passi
. Rivedere illink:configure-reqs-sn2100-cluster.html["requisiti di configurazione"] .
. Seguire le istruzioni nel link:https://networking-docs.nvidia.com/sn2000hw/latest["Guida all'installazione dello switch NVIDIA"^].


.Cosa succederà ora?
Dopo aver installato l'hardware, puoilink:cabling-considerations-sn2100-cluster.html["rivedere il cablaggio e la configurazione"] requisiti.
