= Flusso di lavoro per l'installazione del software sugli switch di cluster Cisco Nexus 3132Q-V
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Segui questo workflow per installare il software NX-OS e il file di configurazione di riferimento (RCF) sugli switch di cluster Cisco Nexus 3132Q-V.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Uno"]link:setup-switch.html["Configurare l'interruttore"]
[role="quick-margin-para"]
Configura lo switch di cluster 3132Q-V.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Due"]link:prepare-install-cisco-nexus-3132q.html["Prepararsi all'installazione del software NX-OS e RCF"]
[role="quick-margin-para"]
Il software Cisco NX-OS e l'RCF devono essere installati sugli switch di cluster Cisco 3132Q-V.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Tre"]link:install-nx-os-software-3132q-v.html["Installa o aggiorna il software NX-OS"]
[role="quick-margin-para"]
Scarica e installa o aggiorna il software NX-OS sullo switch di cluster Cisco 3132Q-V.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Quattro"]link:install-upgrade-rcf-overview-3132q-v.html["Installare o aggiornare l'RCF"]
[role="quick-margin-para"]
Installare o aggiornare l'RCF dopo aver configurato lo switch Cisco 3132Q-V.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["Cinque"]link:configure-ssh-keys.html["Verifica la configurazione SSH"]
[role="quick-margin-para"]
Verificare che SSH sia abilitato sugli switch per utilizzare le funzionalità di monitoraggio dello stato dello switch Ethernet (CSHM) e di raccolta dei registri.
